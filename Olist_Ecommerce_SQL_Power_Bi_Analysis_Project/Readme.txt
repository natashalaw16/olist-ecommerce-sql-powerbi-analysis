Project Title:
Olist E-Commerce Marketplace Analysis (SQL + Power BI)

Tools Used:

SQL Server

Power BI

Project Description:

Analyzed the Olist e-commerce dataset to explore sales performance, customer behavior, seller performance, and delivery efficiency. SQL was used to perform data analysis and aggregation, while Power BI was used to visualize key insights through interactive dashboards.

Key Insights:

Calculated total GMV and analyzed monthly sales trends

Identified top product categories and customers by revenue

Analyzed seller performance and review ratings

Evaluated late delivery rates and their impact on customer reviews

Examined payment method distribution
